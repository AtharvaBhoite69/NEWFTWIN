# Card Images — Drop Images Here

Place card images in this folder. FTWIN will automatically pick them up on the next server restart.

## Naming Convention (for auto-matching)

Name your image files to match the card name or bank name so FTWIN can automatically link them:

| Card | Suggested filename |
|------|--------------------|
| HDFC Millennia Credit Card | `hdfc_millennia.jpg` |
| SBI SimplyCLICK Credit Card | `sbi_simplyclick.png` |
| ICICI Coral Credit Card | `icici_coral.jpg` |
| Axis Ace Credit Card | `axis_ace.png` |
| Amex Membership Rewards | `amex_membership_rewards.jpg` |

## Supported Formats
- `.jpg`, `.jpeg`, `.png`, `.webp`

## How It Works
1. Drop image files here.
2. FTWIN matches each filename against the card catalog (by card name + bank).
3. On server restart, matched images are linked automatically.
4. Unmatched images are staged for manual assignment.

## Image Specifications
- Recommended size: **856×540px** (standard credit card aspect ratio 1.586:1)
- File size: Keep under 2MB per image for best performance
